Privacy Policy

Last updated: October 11, 2026

SaveWise is a demonstration website that helps visitors find official ways to save content they own or are authorized to download. This policy describes the current static starter version. Update it if you add analytics, advertising, server functions, or other services.

Links you enter

The URL checker runs in your browser. It parses the URL to identify whether it belongs to Instagram, TikTok, Facebook, or YouTube. The current version does not send the entered URL to an application server, store it in local storage, or retrieve media from it.

Hosting and technical data

The site is intended to be hosted on Cloudflare Pages. Hosting providers may process technical request data, such as IP address, browser information, and request logs, as described in their own policies. Review Cloudflare’s current privacy documentation before publishing.

Cookies and analytics

This starter website does not intentionally set analytics or advertising cookies and does not include third-party analytics scripts. External links open official platform help pages; those services operate under their own privacy policies.

Children

This website is not designed to collect personal information from children. Do not submit personal or sensitive information in a URL.

Changes

If functionality or data practices change, update this policy before deploying the change. This template is informational and is not legal advice.
